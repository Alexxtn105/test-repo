# Персональный сайт

Персональный сайт, созданный с использованием современных веб-технологий. Проект включает в себя красивый дизайн с плавными анимациями и адаптивной версткой.

## Основные особенности

- Современный дизайн в стиле Apple
- Плавные анимации и переходы
- Адаптивная верстка для всех устройств
- Оптимизированная производительность
- Параллакс-эффекты на главной странице

## Технологии

- [Next.js 14](https://nextjs.org/) - React фреймворк для production
- [Tailwind CSS](https://tailwindcss.com/) - CSS фреймворк для быстрой стилизации
- [Framer Motion](https://www.framer.com/motion/) - Библиотека анимаций для React
- [Lucide React](https://lucide.dev/) - Набор иконок для React
- TypeScript для типизации

## Команды разработки

### Запуск в режиме разработки

```bash
npm run dev
```

Откройте <http://localhost:3000> в браузере, чтобы увидеть результат.

### Сборка проекта

```bash
npm run build
```

### Запуск собранного проекта

```bash
npm run start
```

### Проверка типов и линтинг

```bash
npm run lint
```

## Структура проекта

```
app/                  # Основные страницы приложения
  ├── page.tsx        # Главная страница
  ├── layout.tsx      # Общий layout приложения
  └── globals.css     # Глобальные стили
components/           # Компоненты пользовательского интерфейса
lib/                  # Вспомогательные функции и утилиты
```

## Основные компоненты

- `Hero` - Главный раздел с параллакс-эффектами
- `Features` - Секция с описанием возможностей

## Экспорт статического сайта

Проект настроен для экспорта в виде статического сайта с помощью конфигурации Next.js:

```js
// next.config.js
const nextConfig = {
  output: 'export',
}
```

После выполнения команды `npm run build` статический сайт будет доступен в директории `out`.

## Деплой

Проект можно легко развернуть на различных платформах:

- Vercel (рекомендуется для Next.js приложений)
- Netlify
- GitHub Pages
- Любой статический хостинг

Для деплоя на Vercel просто подключите репозиторий к вашему аккаунту Vercel и следуйте инструкциям.
